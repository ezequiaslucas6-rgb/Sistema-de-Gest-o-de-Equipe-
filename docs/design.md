Distinctive thread: network operations console. The app reads like a NOC wallboard made precise and calm: hairline 1px rules instead of heavy cards, tabular mono numerals for every count, date and hour, and a single signal color (fiber teal) reserved for "working / covered". Status is shown by shape and weight first (filled cell = trabalho, hollow/hatched = folga, outlined amber = desfalque, red rule = cobertura abaixo do mínimo), color second.
Modes: both light and dark. Light is cool paper (blue-grey tinted off-white), dark is deep graphite slate.
Pacing: tight. This is a working tool for a supervisor: compact rows, dense grids, small caps labels, no hero sections.
Global character: flat surfaces separated by hairline borders, small radii (4-6px), almost no shadow except popups. Display face Bricolage Grotesque for page titles and big numbers; IBM Plex Sans for UI; JetBrains Mono for numerals, dates, codes (EQ-01, S1). Uppercase tracked micro-labels for section headers. Sector identity: Suporte Técnico uses the primary teal, Infraestrutura Backbone uses a deep indigo ink (--sector-infra) — the only second hue allowed.
